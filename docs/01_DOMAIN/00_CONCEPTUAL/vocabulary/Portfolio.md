## Portfolio

Definición

Conjunto completo del patrimonio coleccionable del usuario.

Contiene todas las colecciones.

No representa una colección individual.

Ejemplos

Portfolio

├── LEGO

├── Nintendo

├── Transformers

├── Rubik

└── Monster Trucks

Palabras prohibidas

✘ Collection (cuando nos referimos al conjunto completo)

✔ Portfolio
