# Palabras Prohibidas

Las siguientes palabras NO deberán utilizarse dentro del proyecto.

| Incorrecto | Correcto |
|------------|----------|
| User | Collector |
| Item | Collectible |
| Product | Collectible |
| Buy | Acquire |
| Sell | Dispose |
| Money | Strategic Capital (cuando proceda) |
| Collection (patrimonio completo) | Portfolio |
| List | Portfolio |
| Value | Strategic Value |
| Score | Strategic Investment Score / SDQ |
| Price | Market Price / Target Price |
| Owned | Acquired |
| Missing | Pending Acquisition |
| Cheap | Opportunity |
| Expensive | Above Target Price |
